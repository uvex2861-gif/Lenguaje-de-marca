1. ¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje de marcado con el que se describe el contenido de una página web. No es un lenguaje de programación: no calcula ni toma decisiones, sino que indica qué es cada parte del contenido, por ejemplo un título, un párrafo o una imagen.

El navegador lee el código HTML y lo convierte en la página que vemos. Junto con CSS, que se encarga del aspecto, y JavaScript, que añade comportamiento, forma la base de casi todo lo que se ve en internet.

2. Estructura de una página

Todo documento HTML empieza con la declaración <!DOCTYPE html> y se envuelve en la etiqueta <html>. Dentro hay dos bloques principales: <head>, con información sobre la página como el título o la codificación, y <body>, con el contenido visible.

Es importante indicar siempre <meta charset="UTF-8"> en el head; así los acentos y la letra ñ se muestran bien. También conviene declarar el idioma con lang="es" en la etiqueta html.

3. Títulos y párrafos

Los títulos se escriben con las etiquetas <h1> a <h6>, de mayor a menor importancia. Lo recomendable es usar un único h1 por página y emplear los demás niveles para organizar el contenido en secciones y subsecciones.

Los párrafos de texto se marcan con <p>. El navegador separa cada párrafo del siguiente de forma automática, así que no hace falta añadir saltos de línea a mano; para eso existe <br>, que se reserva para casos concretos como una dirección postal.

4. Enlaces

Los enlaces se crean con la etiqueta <a> y su atributo href, que indica el destino. Pueden apuntar a otra página de internet, a otro archivo de nuestro propio sitio o incluso a un punto concreto de la misma página mediante un ancla.

El texto del enlace debe ser descriptivo. Una frase como «pincha aquí» no dice nada a quien usa un lector de pantalla ni a los buscadores; es mucho mejor indicar claramente a dónde lleva, por ejemplo «descargar la guía de instalación».

5. Listas

HTML ofrece listas sin orden, con <ul>, y listas ordenadas, con <ol>. En ambos casos cada elemento se escribe dentro de una etiqueta <li>. Las listas sin orden se muestran con viñetas y las ordenadas con números.

Las listas son muy útiles para construir menús de navegación, ya que un menú no deja de ser una lista de enlaces. Más adelante, con CSS, se puede cambiar por completo su aspecto para que parezcan botones o una barra horizontal.
