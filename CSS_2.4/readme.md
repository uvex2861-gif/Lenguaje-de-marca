(1) ¿qué diferencia hay entre margin y padding?
Ambos añaden espacio alrededor del contenido, pero en lados distintos.
(2) ¿por qué saltaba la tercera tarjeta de línea?
Porque ocupaba mas espacio de anchura del que podia soportar con las tarjetas
(3) ¿qué propiedades ignoraba el <span> y por qué?
ignoraba el width y el height, porque cuando tiene puesto display: inline ignora esas propiedades 
(4) ¿qué hace display: none con el espacio que ocupaba la caja?
Con display:none el elemento deja de dibujarse y no ocupa espacio,sí que la tarjeta 3 desaparece.
