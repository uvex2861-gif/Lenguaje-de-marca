Ficha técnica: Git

Descripción

Git es un sistema de control de versiones distribuido que permite registrar los cambios realizados en los archivos de un proyecto y coordinar el trabajo entre varias personas. Fue creado por Linus Torvalds y publicado por primera vez el 7 de abril de 2005.

Uso básico

Para crear un repositorio nuevo en la carpeta actual se usa el comando git init. Para guardar los cambios en el historial:

git commit -m "Primer commit"

Recuerda guardar los archivos en tu IDE con Ctrl + S antes de hacer el commit.

Servicios relacionados

Git se suele utilizar junto a plataformas como GitHub, que ofrecen una API para automatizar tareas. Actualmente la versión mayoritaria es la 2.x1.

1 Numeración de versiones según la web oficial del proyecto.
