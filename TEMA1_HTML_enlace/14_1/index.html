Enlaces de interés para desarrollo web

Una pequeña recopilación de recursos que resultan muy útiles al aprender HTML, CSS y JavaScript.

  • MDN Web Docs: la documentación de referencia de la web
  • W3Schools: tutoriales de HTML con ejemplos
  • Validador de W3C: comprueba que tu HTML es correcto
  • GitHub: alojamiento de código y control de versiones
  • Can I use: compatibilidad de funciones web con cada navegador
